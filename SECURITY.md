# Security

## Reporting

If you find a security issue, open a private report on GitHub or email the repository owner. Do not file public issues for undisclosed vulnerabilities.

## Scope

This project is a **static site**: JSON data, Astro build output, and client-side React. There is no server, database, authentication, or user-upload path in the deployed app.

## Deployed site

Public static hosting (no login): **https://lazzzarov.github.io/spanish-banking-map/**

## Before publishing

- No `.env`, API keys, tokens, or credentials in the tree (last pre-publish grep: no matches in tracked source; dependency advisories tracked via `npm audit`).
- `data/` contains only curated public URLs and institution metadata.
- No scrapers, news ingest, or automated logo download in the repository (trademark risk and supply-chain surface).
- Bank logos use optional local files or generated monograms only.

## Hardening in place

- **Content Security Policy:** every page carries a CSP `<meta>` tag generated by Astro (`security.csp` in `astro.config.mjs`). Scripts and stylesheets are limited to the site itself plus hashes of its own inline code; no third-party origins are allowed.
- **No third-party requests:** fonts are bundled from `@fontsource` packages instead of Google Fonts.
- **Data links:** `npm run validate` rejects any source URL that is not `https://`.
- **CI:** GitHub Actions are pinned to commit SHAs, checkout does not persist credentials, and the workflow only has the permissions Pages needs.

## Dependencies

Dependabot (`.github/dependabot.yml`) proposes weekly npm and GitHub Actions updates. Run `npm audit` after `npm install`. CI runs `npm test`, `npm run validate` and `npm run build` on every push to `main`.
